# Low-poly торговый порт

Самостоятельный build_market_harbor.py не требует внешних файлов или дополнений. Модель создаётся у начала координат в коллекции ReferenceMarketHarbor. Коллайдеры — в ReferenceMarketHarbor_Collision; они скрыты в рендере и окне просмотра, при необходимости включите их в Outliner.

1. Откройте Blender и перейдите в рабочее пространство Scripting.
2. В Text Editor нажмите New.
3. Вставьте весь код из build_market_harbor.py.
4. Нажмите Run Script (Alt+P). Затем сохраните сцену через File → Save As.

Готовая модель: MarketHarbor.blend. Превью: MarketHarbor_Preview.png.

Проверено в Blender 5.2.1: два запуска без дублирования объектов, корень 0,0,0, scale 1,1,1, flat shading, отсутствие полигонов нулевой площади. 24 984 визуальных треугольника, 17 коллайдеров. Самостоятельный скрипт не сохраняет файлы автоматически и не удаляет сторонние объекты сцены.

Это low-poly реконструкция по одному ракурсу, а не точное измерение объекта: скрытая геометрия восстановлена приблизительно. Коллайдеры охватывают основные статические массы, дома, причалы и лестницы; мелкие декорации не имеют собственной физики. Автоматическая проверка ходьбы в Unity для этой модели не выполнялась.
