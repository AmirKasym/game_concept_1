# Попутный ветер — прототип 02

Парусный корабль, прогулка и прыжки на палубе, стилизованные матросы и начальный LAN-кооператив на 2–4 игроков. Основа — документы в `Docs/Source`. Второй этап начат; торговля и полноценный рейс ещё впереди.

## Запуск

1. Открыть проект в Unity **6000.6.0f1** и дождаться импорта пакетов.
2. Выбрать **Trade Winds → Play First Voyage**. Команда готовит сцену и запускает именно её.
3. Щёлкнуть по окну **Game**. Если открыта пауза, нажать **Вернуться на палубу** или Esc.

Сцена `Assets/TradeWinds/Scenes/FirstVoyage.unity` сохраняет геометрию корабля, океана и островов: мир виден и до Play. Материалы и меши находятся в `Assets/TradeWinds/Generated`. Матросы создаются при запуске; Tab показывает своего персонажа снаружи.

Windows-сборка: **Trade Winds → Build Windows prototype**, результат — `Builds/Windows/FirstVoyage.exe`. Для запуска нужны также соседние файлы и папка `FirstVoyage_Data`.

## Управление

| Клавиши | Действие |
|---|---|
| WASD или стрелки | Ходить |
| Мышь | Смотреть |
| Пробел | Прыгать; у штурвала сначала отпустить его |
| Shift | Бежать |
| E рядом со штурвалом | Взяться / отпустить |
| W / S за штурвалом | Поставить / убрать парус |
| A / D за штурвалом | Повернуть руль |
| B за штурвалом | Поднять / опустить якорь |
| F рядом с переносимым ящиком | Поднять / поставить |
| Tab | Внешняя камера / первый человек |
| Esc | Меню, настройки и кооператив |
| R в одиночной игре | Начать выход заново |

Первый выход: **E → B → удерживать W**. Пробел больше не управляет якорем.

## Кооператив

На первом компьютере: Esc → **Создать игру**. На втором: Esc → ввести локальный адрес компьютера хоста → **Подключиться**. Для двух окон на одном компьютере адрес — `127.0.0.1`, порт — `7777`.

Хост считает движение корабля, позиции матросов, занятость штурвала и перенос ящика. Клиенты передают команды клавиш. Ящик может нести только один игрок. Меню в сетевой игре останавливает ввод своего игрока, но весь рейс продолжается. Разрыв соединения освобождает штурвал и ящик. Steam-лобби и подключение через интернет пока не реализованы.

## Графика

Небо с облаками и солнцем, блики и рябь на воде, тёплое освещение, детализированная палуба, фонари и причал у маяка. Модели матросов созданы из общих мешей: лицо, фуражка, куртка, полосатая рубашка, брюки и ботинки. Есть анимация ходьбы и поза переноса груза. Цвета одежды различаются у игроков.

## Проверки

`Tools/Test-Core.ps1` проверяет 19 сценариев движения и состояния корабля без Unity. Отчёт — `TestResults/core-tests.txt`.

Development-сборка поддерживает автоматическую проверку реального клавиатурного ввода и сети:

```text
FirstVoyage.exe --voyage-smoke host C:/path/to/results
FirstVoyage.exe --voyage-smoke client C:/path/to/results
```

Сначала запускается хост, через несколько секунд — клиент. Результаты и кадры записываются в указанную папку. Проверка не включается в обычном запуске.

## Границы прототипа

Пока нет торговли, контрактов, ремонта, Steam, звука и сохранения рейса. Передвижение ограничено палубой; нельзя сойти на остров или выпасть за борт. При подходе к скалам корабль останавливается. Сетевая схема ещё требует проверки четырьмя игроками, повторных подключений и работы при задержках. Текущие результаты проверок — в `Docs/Validation.md`.
