# Попутный ветер — первый рейс

Первый одиночный прототип кооперативной игры о торговом корабле. Рабочее название временное. Реализуется **этап 1 технического брифа: ощущение корабля**.

## Запуск

Автоматическая подготовка на Windows (докачка официального Editor, проверка установщика, установка и сборка):

```powershell
powershell -ExecutionPolicy Bypass -File .\Tools\Setup-And-Build.ps1
```

Состояние — `TestResults/setup-status.json`, лог Unity — `TestResults/unity-build.log`. Скрипт сохраняет частичную загрузку и продолжает её при повторном запуске. При запросе Windows потребуется подтверждение установки; лицензия Unity активируется пользователем через Hub. Готовый билд сам по себе не подтверждает визуальное качество и управление.

Ручной вариант:

1. Установить Unity Editor **6000.0.62f1** через Unity Hub, с модулем Windows Build Support. Версия зафиксирована для воспроизводимости, это не рекомендация «самой новой» версии.
2. Unity Hub → **Add → Add project from disk** → выбрать эту папку, где находятся `Assets`, `Packages`, `ProjectSettings`.
3. Открыть проект и дождаться загрузки URP / Input System и завершения компиляции. Первый импорт требует интернета.
4. Скрипт редактора автоматически создаст настройки URP и `Assets/TradeWinds/Scenes/FirstVoyage.unity`. Если сцена не открылась, открыть её из окна Project. Повторная подготовка: **Trade Winds → Prepare prototype**.
5. Нажать **Play**, затем щёлкнуть по окну Game. Если Unity запросит перезапуск для Input System, согласиться и открыть проект снова.

Геометрия сцены создаётся **при Play**: пустая иерархия с одним объектом `First Voyage` до запуска ожидаема. Внешние модели, текстуры и Asset Store не нужны.

## Что уже в коде

- Небольшой парусный торговец: корпус, палуба, мачта, парус, штурвал, закреплённые ящики.
- Прогулка от первого лица; взаимодействие со штурвалом по расстоянию.
- Парус, ветер, разгон, инерция поворота, торможение якорем.
- Два слоя волн: единые формулы воды и качки корабля.
- Компактное тестовое море, остров с маяком и две дополнительные скалы.
- Русский HUD, три задачи знакомства, внешний вид корабля, пауза.
- Настройки чувствительности, качки камеры, обычной/низкой графики, тест сильного волнения.
- Автоматическая подготовка сцены и команда сборки Windows.

## Управление

| Клавиши | Действие |
|---|---|
| WASD + мышь | Ходить по палубе и смотреть |
| Shift | Быстрая ходьба |
| E рядом со штурвалом | Взяться / отпустить |
| W / S за штурвалом | Увеличить / уменьшить парус |
| A / D за штурвалом | Руль влево / вправо |
| Пробел за штурвалом | Поднять / опустить якорь |
| Tab | Внешняя камера / первый человек |
| Esc | Пауза и настройки |
| R | Сбросить корабль и игрока в исходную точку |

Первое упражнение: подойти к штурвалу → E → Пробел → удерживать W до постановки паруса → пройти 100 м → E → пройтись по палубе. Парус продолжает работать после отпускания штурвала. S убирает парус, заднего хода нет.

## Проверки и сборка

Локальная проверка модели движения без Unity:

```powershell
powershell -ExecutionPolicy Bypass -File .\Tools\Test-Core.ps1
```

Windows-билд в редакторе: **Trade Winds → Build Windows prototype**. Результат: `Builds/Windows/FirstVoyage.exe`.

Пример для установленного редактора из командной строки:

```powershell
& 'C:\Program Files\Unity\Hub\Editor\6000.0.62f1\Editor\Unity.exe' -batchmode -quit -projectPath $PWD.Path -executeMethod TradeWinds.Editor.PrototypeSetup.BuildWindows -logFile build.log
```

Состояние фактической проверки: [Docs/Validation.md](Docs/Validation.md). Порядок ручного испытания: [Docs/Playtest.md](Docs/Playtest.md).

## Границы этой итерации

Это исходники первой тестовой сцены, **не готовый вертикальный срез**. Нет торговли, контрактов, сетевого коопа, Steam, подвижного груза, ремонта, звука и сохранения. Ящики пока статичны. Падение за борт и прыжок исключены; движение ограничено палубой. Настройки действуют на текущий запуск. Сильная качка — переключатель проверки, не сценарный шторм.

При подходе слишком близко к скалам корабль останавливается; R возвращает его в безопасную точку. Это временная защита тестовой сцены, а не готовая система столкновений. Кооп и взаимодействие с грузом — следующий этап после проверки управления в Unity.

На момент подготовки исходников проект ещё не запускался в Unity: установлен Hub, загрузка Editor продолжается. Актуальное состояние автоматической подготовки записывается в `TestResults/setup-status.json`. Мост MCP не подключён; для компиляции и сборки используется командная строка Editor.

Техническая база: [зафиксированный выпуск Unity](https://unity.com/releases/editor/whats-new/6000.0.62f1), [URP 17](https://docs.unity.cn/Packages/com.unity.render-pipelines.universal@17.0/manual/universalrp-asset.html).
